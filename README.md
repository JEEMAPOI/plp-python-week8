# Personal Mini-Toolkit

## Project Description

The Personal Mini-Toolkit is a Python program that provides three useful tools through a menu-driven interface.

### Tools Included

1. **Number Guessing Game:** The computer selects a random number between 1 and 10, and the user guesses until they find it.
2. **To-Do List:** Allows users to add, view, and remove tasks.
3. **Name Formatter:** Formats a user's full name with proper capitalization.

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code or a terminal.
4. Run the following command:

```bash
python toolkit.py
```

## Technologies Used

- Python
- Variables and input/output
- If, elif and else statements
- While and for loops
- Lists
- Functions and string methods
- F-strings

## Reflection

The hardest part of this project was building the menu-driven program and making sure it returned to the main menu after each tool. The bug that took the longest to fix was handling user input correctly in the Number Guessing Game and To-Do List. I learned how to use loops, lists, conditionals, and f-strings in a practical project. I also learned how to add and remove items from a list using append() and pop(). Testing each tool helped me understand how the different parts of the program work together. If I had one more week, I would add a calculator and save To-Do List tasks to a file so they are available after closing the program.
